# yuxaconsultancy.com

The website of YUXA Consultancy, a small team in Istanbul, generated by
`build.py` from `content.py` and served by GitHub Pages at
<https://yuxaconsultancy.com>.

| Path                                    | Page                                              |
|-----------------------------------------|---------------------------------------------------|
| `/`, `/en/`, `/fr/`                     | Home: services, prices, workshops, team, contact  |
| `/ahsap/`, `/en/woodwork/`, `/fr/bois/` | Durmuş Uyu's woodwork: photographs, commissions, workshops |
| `/atolye/`                              | The LaTeX ile Tez workshop, in Turkish            |

## Edit and build

Change the words in `content.py`, then:

```sh
python3 build.py   # standard library only; writes the HTML, sitemap and robots.txt
```

Commit the generated files with the change; GitHub Pages serves them as they are.

## Adding a person

1. Add an entry to `TEAM` in `content.py`: name, and role and bio in each
   language. The team section of the home pages lists it.
2. Give the person's services and workshops a `by` line in `PAGES`.
3. If their work is best shown in pictures, give them a work page: a dict like
   `WOODWORK`, registered in `WORK_PAGES` under a key that `nav` and their
   `TEAM` entry use. Its photographs go in `assets/<topic>/`, made by
   `make photos` in the private repository.

## Settings in `content.py`

| Setting         | When empty                         |
|-----------------|------------------------------------|
| `WHATSAPP_LINK` | No WhatsApp button anywhere        |
| `BOOKING_LINK`  | Booking buttons open an e-mail     |
| `WORKSHOP_FORM` | Workshop registration by e-mail    |

`WHATSAPP_LINK` must be a WhatsApp Business short link
(`https://wa.me/message/...`), which does not reveal the phone number.

## Rules

This repository is public. No phone numbers, no addresses, nothing private: not
in the pages, not in the source, not in a commit message. Photographs come here
only as copies stripped of their metadata (camera data, GPS positions).

## Assets

- `assets/fonts/`: Go Regular, Italic, Medium and Bold, subset to Latin and
  compressed to WOFF2; licence in `assets/fonts/LICENSE-Go.txt`. Made with:

  ```sh
  pyftsubset Go-Regular.ttf --flavor=woff2 --layout-features='kern,liga,calt,locl' \
    --unicodes='U+0000-007E,U+00A0-017F,U+2010-2014,U+2018-201E,U+2022,U+2026,U+202F,U+2032-203A,U+20AC,U+2122,U+2190-2193,U+2212'
  ```

- `assets/favicon.svg`: `python3 tools/make_favicon.py`; the touch icon is
  `rsvg-convert -w 180 -h 180 assets/favicon.svg -o assets/apple-touch-icon.png`.
- `assets/og.png` and `assets/og-woodwork.jpg`: the social previews of the site
  and of the woodwork pages, typeset in LaTeX in the owner's private
  repository and rendered at 1200 × 630.
- `assets/woodwork/`: photographs of Durmuş Uyu's work, `<name>-1000.jpg` for
  the page and `<name>-2000.jpg` for the full view, made by `make photos` in
  the private repository, which keeps the originals.
